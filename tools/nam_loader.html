Your effect is ready

  1. Download the named ZDL and keep its capture notes. Your icon and name are on its pedal screen. For the Effect Manager thumbnail, download the PNG beside the ZDL, keeping their matching names.
  2. Add it in Zoom Effect Manager and install it. Different capture slots can remain installed together.
  3. Close Effect Manager, reconnect Patch Editor and select your named capture in the Custom list. On the pedal, find NAM-shortname under Delay, version 0.23.
  4. Test one capture at a time: Input 50 · Output 25 · Mix 100. Compare with bypass or Mix 0.

216 independent capture slots; original NAMLite is unchanged. Reusing a slot replaces that capture in every patch using it. Installing several does not guarantee enough DSP to run them simultaneously.

Slot names are remembered in this browser. Keep using the same browser and address. If you clear browser storage or use another computer, use your saved capture notes to identify occupied slots before exporting. Patch Editor still recognizes every slot's ID as a generic capture slot.

Frequency response

    An amp's tone depends on how hard you play it, so the capture is measured with pink noise at three input levels; each curve is the part of the output that follows the input, levelled in the mids so the shapes compare. Through a cab, it is the chain as the pedal plays it: the capture, then the cab's pedal filter.

    Cabinets — CabIR

    Each cab IR becomes its own CabIR effect, the same way each capture becomes its own NAM effect: pick it from the slot's effect list, no Cab knob. Up to 216 cabs (slots 1–16 are IDs 930–945, 17–216 are 700–899). One cab costs about 5% of NAM's load, so it fits after a capture. Each IR is fitted as a short FIR plus six filters, in this browser.

    44.1 or 48 kHz, mono or stereo, up to 2 s. Fitting takes a few seconds per IR. Use amp-only NAM captures in front of a cab.

      Loading the cab engine…

      Each cab keeps its slot, so patches never switch cab under you. Removing a cab frees its slot for the next one you add; remove its file in Effect Manager too. Cabs are remembered in this browser.

      Which captures work?

      This experimental loader accepts the specific 3-channel A2 Lite WaveNet layout used by our tested captures, including compatible Lite models inside a SlimmableContainer. Other NAM architectures and larger models are rejected.

      The pedal processes at 44.1 kHz. A 48 kHz capture currently runs without sample-rate conversion, so its tone and timing can differ from the original. Successful conversion does not establish faithful playback or enough processing power to combine it with other effects.

      Use a computer with Effect Manager for installation. Patch Editor edits an installed effect; it does not install the NAM file.
