# Clean LCD cover pilot

Stasis, Spool and Rooms have been adapted from the comparison concept to native 128×64 monochrome covers, embedded in `dist/*.ZDL`. Gallery PNGs are decoded from those binaries, without the decorative VHS filter.

The original gallery images and Spool bitmap override are preserved in `originals/`. The active artwork is generated by `src/airwindows/common/custom_covers.py`; Spool no longer uses the override.

Validation: all three binary covers decode to 128×64. The first pilot retained value positions (14,46), (55,46), (96,46). The stock-style follow-up moves Stasis to y=11; Spool and Rooms retain y=46. Release initialization verification passes. Physical pedal display confirmation is still needed after installing the three rebuilt effects. No DSP changes are part of this artwork pass.

Rebuild with `python3 build_all.py stasis tapeecho4 rooms`, then `python3 build/make_gallery_png.py Stasis Spool Rooms`.

## Stock-style follow-up

`stock-style/comparison.png` shows decoded binary pixels at 2× and 1×, no invented value overlays. `stock-style/index.html` uses the actual PE drawCover function, copied when the preview is generated. No high-resolution artwork or texture is added. Run `python3 graphics/effect-cover-explorations/stock-style/render_preview.py` from the repository root to regenerate.

Artwork and firmware positions are defined together in `src/airwindows/common/stock_style_covers.py`. Stasis uses a top control panel and frozen-wave nameplate; Spool a reel deck; Rooms a perspective room with architectural lettering. Only these three effects are changed. Physical LCD pixel proportions and the firmware's exact value glyphs are not emulated by the preview.

The latest preview omits simulated numbers: the pedal controls the actual live value glyphs. Knobs now have equal horizontal and vertical pixel diameters in PE. Earlier `*-values-simulation.png` files are superseded mockups, not hardware captures.

## Hardware pixel aspect correction

The user's Spool pedal photo (2026-09-14 12.39.44) showed the square-pixel
reels stretched vertically. The revised geometry uses an approximate 1.4
pixel height/width ratio, shared by the art generators and gallery renderer
through build/lcd_geometry.py. PE cover canvases now use a 10:7 physical
aspect instead of their intrinsic 2:1 bitmap ratio. Stock-style circles use
elliptical raster footprints so the LCD stretch restores approximately round
shapes. Preview shows LCD proportions and separately labels the raw bitmap.
Physical roundness still needs hardware confirmation; camera perspective and
integer pixel rounding limit accuracy. Dist Stasis/Spool/Rooms and the Rooms6
probe have been rebuilt. Previous square-pixel preview claims are superseded.
